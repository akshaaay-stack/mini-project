# Student Marks Analyzer

## About

Student Marks Analyzer is a C++ mini project created to make basic student mark analysis easier.

The program takes students' marks as input and processes them to generate a simple performance report. It helps organize marks and understand students' overall performance.

## What This Project Does

- Takes marks as input.
- Calculates the total marks.
- Finds the average marks.
- Identifies the highest and lowest marks.
- Counts the number of students who passed.
- Displays the results in a report format.

## Built With

- C++
- Visual Studio Code
- GCC Compiler

## How to Run

Make sure you have a C++ compiler installed.

**1. Compile the program**

```bash
g++ main.cpp -o analyzer
```

**2. Run the program**

On Windows PowerShell:

```powershell
.\analyzer.exe
```
